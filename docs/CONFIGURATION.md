# Configuration

이 문서는 k8s-lsp(서버) + Kubernetes LSP(VS Code 확장)의 설정을 한곳에서 정리하기 위한 단일 레퍼런스입니다.

현재는 Phase 1에서 링크가 깨지지 않도록 스텁으로 추가되어 있으며, 설정 키/기본값/예시는 Phase 2에서 확장됩니다.
